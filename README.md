# DEV Group

Корпоративный сайт для devgroup.kz. Главная страница и одиннадцать страниц проектов готовы к размещению на обычном статическом хостинге. Для просмотра сайту не нужны Node.js, база данных или сторонние шрифты.

## Публикация

Корень репозитория — корень сайта. Разместите `index.html`, каталоги `assets/` и `projects/`, а также `robots.txt` и `sitemap.xml` в каталоге домена. На веб-сервере должен быть включён индексный файл `index.html` для вложенных каталогов. В GitHub Pages источником может служить корень ветки `main`, если тариф аккаунта поддерживает Pages для этого репозитория.

Файл `CNAME` содержит `devgroup.kz`. Домен и сертификат HTTPS подключаются в настройках выбранного хостинга.

## Редактирование

Описания, ссылки и отметки «Скоро» находятся в `tools/projects.json`. После изменения выполните `node tools/build.cjs` и сохраните обновлённые HTML-страницы вместе с исходниками. Генератор использует только стандартные модули Node.js.

Оформление и обработчики формы находятся в `assets/site.css` и `assets/site.js`. Контактный номер задаётся в `tools/build.cjs`. Форма открывает черновик в WhatsApp. Отправку подтверждает посетитель в самом WhatsApp.
